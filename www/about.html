1점수 입력
2대학·학과 기준과 비교
3지원 구간 확인
AIAI 기술로 개발한 서비스예요. 결과 계산은 입력 점수와 대학·학과별 기준 데이터를 비교하는 방식이에요.
이런 걸 할 수 있어요
🎯
점수 진단

점수를 넣으면 대학·학과별 기준 데이터와 비교해 지원 구간을 보여줘요.

📈
목표점수 코칭

지금 점수와 목표 사이의 거리를 구간으로 보여주고, 무엇을 보완하면 좋을지 짚어줘요.

🧮
전형료 계산기

지원할 대학을 담기만 하면 전형료 합계가 자동으로 계산돼요.

📚
기출·논술 허브

논술 실시 대학과 기출 자료를 대학별로 찾아볼 수 있어요.

💰
등록금·장학

대학알리미 공시 자료를 정리해 등록금과 장학 정보를 보여줘요.

데이터 출처
  • 대학알리미
  • 각 대학 모집요강
  • 커리어넷 직업백과
  • 정책브리핑(공공누리 제1유형)

출처 자료는 공개 시점 기준이라 최신 내용과 다를 수 있어요. 지원 전에는 각 대학 공식 사이트를 확인해 주세요.
